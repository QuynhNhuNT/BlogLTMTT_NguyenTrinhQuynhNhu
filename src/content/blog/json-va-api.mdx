JSON (JavaScript Object Notation) là định dạng dữ liệu phổ biến nhất để trao đổi thông tin giữa client và server.

## JSON là gì?

JSON là định dạng text đơn giản để lưu trữ và truyền tải dữ liệu có cấu trúc.

```json
{
  "name": "Quỳnh Như",
  "age": 20,
  "city": "Hồ Chí Minh",
  "skills": ["JavaScript", "Networking", "Cloud"]
}
```

## JSON.parse() - Parse JSON

Chuyển đổi chuỗi JSON thành JavaScript object:

```js
const jsonString = '{"name":"Quỳnh Như","age":20}';
const obj = JSON.parse(jsonString);
console.log(obj.name); // "Quỳnh Như"
console.log(obj.age); // 20
```

## JSON.stringify() - Stringify Object

Chuyển đổi JavaScript object thành chuỗi JSON:

```js
const person = {
  name: "Quỳnh Như",
  age: 20,
  city: "Hồ Chí Minh"
};

const jsonString = JSON.stringify(person);
console.log(jsonString); // '{"name":"Quỳnh Như","age":20,"city":"Hồ Chí Minh"}'
```

## Làm việc với API

### Fetch API - GET Request

```js
async function fetchUserData(userId) {
  try {
    const response = await fetch(`https://api.example.com/users/${userId}`);
    
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Lỗi:", error);
  }
}

// Sử dụng
fetchUserData(1).then(user => {
  console.log(user);
});
```

### POST Request

```js
async function createUser(userData) {
  try {
    const response = await fetch('https://api.example.com/users', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(userData)
    });
    
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Lỗi:", error);
  }
}

// Sử dụng
createUser({
  name: "Quỳnh Như",
  email: "quynhnhu@example.com"
}).then(result => {
  console.log("User created:", result);
});
```

### PUT và DELETE

```js
// PUT - Cập nhật
async function updateUser(userId, userData) {
  const response = await fetch(`https://api.example.com/users/${userId}`, {
    method: 'PUT',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(userData)
  });
  return await response.json();
}

// DELETE - Xóa
async function deleteUser(userId) {
  const response = await fetch(`https://api.example.com/users/${userId}`, {
    method: 'DELETE'
  });
  return await response.json();
}
```

## Xử lý lỗi API

```js
async function fetchWithErrorHandling(url) {
  try {
    const response = await fetch(url);
    
    if (!response.ok) {
      if (response.status === 404) {
        throw new Error("Không tìm thấy dữ liệu");
      } else if (response.status === 500) {
        throw new Error("Lỗi server");
      }
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    
    const data = await response.json();
    return { success: true, data };
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

## Local JSON Data

Làm việc với JSON trong file:

```js
// data.json
{
  "users": [
    { "id": 1, "name": "Quỳnh Như" },
    { "id": 2, "name": "Người dùng 2" }
  ]
}

// main.js
async function loadData() {
  const response = await fetch('/data.json');
  const json = await response.json();
  console.log(json.users);
}
```

## JSON với Arrays

```js
// Array of objects
const users = [
  { id: 1, name: "Quỳnh Như" },
  { id: 2, name: "User 2" }
];

const json = JSON.stringify(users);
console.log(json); // '[{"id":1,"name":"Quỳnh Như"},{"id":2,"name":"User 2"}]'

const parsed = JSON.parse(json);
console.log(parsed[0].name); // "Quỳnh Như"
```

## Nested JSON

```js
const company = {
  name: "Tech Corp",
  employees: [
    {
      name: "Quỳnh Như",
      department: "IT",
      skills: ["JavaScript", "Networking"]
    }
  ]
};

const json = JSON.stringify(company, null, 2); // 2 spaces indentation
console.log(json);
```

- Xây dựng ứng dụng web hiện đại

Hiểu rõ JSON và API là kỹ năng cần thiết cho mọi web developer!
